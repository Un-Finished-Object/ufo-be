# 추천 도안 조회 제한

[#135](https://github.com/Un-Finished-Object/ufo-be/issues/135)에 따라 `GET /v1/patterns/recommend`의 DB 후보 조회와 응답을 각각 최대 30개로 제한한다.

## 추천 방식

- 비로그인이거나 관심사가 없으면 찜 수와 도안 ID 내림차순의 기본 추천을 반환한다.
- 관심사와 핏 조건에 맞는 도안을 중복 없이 집계하며, 삭제된 도안은 제외한다.
- 도안 ID 오름차순 후보에서 시작 위치를 무작위로 선택해 최대 30개를 조회한다. 끝에서 부족하면 앞부분에서 나머지를 가져오고 반환 순서를 섞는다.
- 후보가 30개보다 적으면 해당 후보만 반환하고, 후보가 없으면 기본 추천으로 전환한다.
