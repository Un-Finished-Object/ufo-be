# 구매 프로젝트 페이지 조회

[#133](https://github.com/Un-Finished-Object/ufo-be/issues/133)에 따라 `GET /v1/users/me/projects`의 구매 내역 병합과 페이지 조회를 DB에서 처리한다.

## 조회 기준

- 대체 실 정보 해금(`YARN_INFO`)과 실제 채팅방 참여를 도안별로 합친다. 두 유형을 모두 구매해도 프로젝트 하나로 센다.
- 삭제된 도안은 목록과 총 개수에서 제외한다. 숨긴 채팅방과 가입 구간이 지난 방의 참여는 포함한다.
- 채팅방 참여가 여러 개이면 참여 시각과 참여 ID 내림차순의 첫 방을 표시한다.
- 대체 실 구매일과 최신 채팅 참여일 중 늦은 시각, 도안 ID 내림차순으로 정렬한다.
- 도안 수를 집계한 뒤 `LIMIT`과 `OFFSET`으로 현재 페이지의 최대 10개만 읽고 응답으로 변환한다. 엔티티 전체를 로딩하지 않는다.
- `nextPage`는 남은 페이지 수를 최대 5까지 반환한다. 빈 결과와 마지막 페이지, 범위를 넘는 페이지는 0이다.
- API에서 `page`를 생략하면 1을 사용하고, 1 미만의 값은 400을 반환한다.
- 서비스를 직접 호출할 때 전달된 `null`이나 1 미만의 페이지 값은 1로 보정한다.
- 오프셋은 `long`으로 계산해 큰 페이지 값의 정수 오버플로를 방지한다.

## 검증

조회 결과를 H2와 MySQL, PostgreSQL에서 같은 테스트로 확인한다. 구매 내역 병합, 구매 시각이 같을 때의 정렬과 최신 채팅방 선택, 사용자별 내역 구분, 삭제 도안 제외, 페이지 경계와 빈 결과를 확인한다. SQL로 조회 건수를 제한하고 엔티티를 불러오지 않는지, 현재 페이지의 이미지 URL만 변환하는지도 확인한다.
